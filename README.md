## 🚀 לנסות את האפליקציה ב-GitHub (בלי להתקין כלום)

### אפשרות א': Codespaces (האפליקציה רצה, ואתה משתמש בה בדפדפן)
1. בעמוד הריפו ב-GitHub: **Code** ← לשונית **Codespaces** ← **Create codespace on `<הענף>`**.
2. מחכים כמה דקות להקמה (ההקמה הראשונה כוללת התקנה ובנייה).
3. הפקודה `npm run demo` רצה אוטומטית ומרימה מסד נתונים, שרת ואפליקציה על כתובת אחת. כשהיא מוכנה, הדפדפן נפתח לבד (או: לשונית **Ports** ← פורט 4000 ← 🌐).
4. נכנסים עם כל מספר נייד ישראלי, ו**קוד הכניסה הוא 123456**.

> כדי לפתוח מהטלפון: בלשונית Ports, קליק ימני על 4000 ← **Port Visibility ← Public**, ואז פותחים את הכתובת בטלפון.
> זו סביבת הדגמה: SMS, סליקה ומיילים מדומים, ונתוני הכיסוי הם להמחשה בלבד.

### אפשרות ב': GitHub Actions (בדיקה אוטומטית עם צילומי מסך)
בכל push, GitHub מריץ את כל הבדיקות, מרים את השרת והאפליקציה ועובר על כל הזרימה בדפדפן אמיתי. צילומי המסך נשמרים בלשונית **Actions** ← הריצה האחרונה ← **Artifacts ← app-screenshots**.

### מקומית, בפקודה אחת
```bash
npm install && npm run demo     # צריך PostgreSQL פעיל. ואז http://localhost:4000
```

## ☁️ הפעלה ב-Render (כתובת קבועה באינטרנט)

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/Gilhzn/NextInLine)

1. לוחצים על הכפתור ונכנסים ל-Render (אפשר עם חשבון GitHub).
2. Render קורא את `render.yaml` ומציג שני רכיבים: מסד נתונים `magiali-db` ושירות `magiali`. לוחצים **Apply** (או **Deploy Blueprint**).
3. אחרי כמה דקות של בנייה מתקבלת כתובת כמו `https://magiali-xxxx.onrender.com`. פותחים אותה בדפדפן או בטלפון.
4. נכנסים עם כל מספר נייד, וקוד הכניסה הוא **123456**.

**חשוב לדעת על התוכנית החינמית של Render:**
- השירות "נרדם" אחרי 15 דקות בלי שימוש, והפתיחה הבאה לוקחת כחצי דקה עד דקה.
- מסד הנתונים החינמי פג אחרי 30 יום. אפשר לשדרג אותו בתשלום.
- קבצי קבלות שהועלו נמחקים כשהשירות מופעל מחדש (אין דיסק קבוע בתוכנית החינמית). הפתרון: Cloudflare R2 בחינם.
- זו **סביבת הדגמה**: קוד כניסה קבוע, ו-SMS, סליקה ומיילים מדומים. לא להזין מידע רפואי אמיתי.
- לחיבור SMS, מייל, אחסון ומסד נתונים אמיתיים בחינם: [docs/free-services.md](docs/free-services.md).

## 🧪 בדיקת הזרימה המלאה, צעד אחר צעד

בהדגמה אין חברת ביטוח אמיתית שעונה, ולכן התשובות שלה מסומלצות ב**ממשק התפעול** (`/ops`).

**1. באפליקציה** (`https://<הכתובת שלך>.onrender.com`):
1. "בוא נתחיל", מספר נייד כלשהו, ואז **"מלא את הקוד"** (או 123456).
2. משפחה: מוסיפים ילד/ה עם תאריך לידה.
3. כיסויים: קופה (למשל מכבי), תוכנית שב"ן (מכבי שלי) וביטוח פרטי (הראל).
4. מפת כיסויים, דילוג על העלאה רטרו, הסכמות וכרטיס (כל מספר. כרטיס שמתחיל ב-`fail_` נדחה).
5. **צלם קבלה** (או בחר תמונה מהגלריה), ואז ממלאים: על מי, סוג השירות (למשל "התפתחות הילד"), תאריך וסכום. אחר כך **"כמה מגיע לי?"**.
6. מסלול הכסף: כמה מהשב"ן וכמה מהביטוח. מעלים מסמך חסר אם התבקש, ולוחצים **"הגש"**.
7. **תיק מוכן להגשה**: כל מה שצריך להגיש. לוחצים "הגשתי".

**2. בממשק התפעול** (`https://<הכתובת שלך>.onrender.com/ops`):
1. קוד הגישה: Render ← השירות `magiali` ← **Environment** ← הערך של `ADMIN_TOKEN` (👁 להצגה).
2. בתור העבודה מופיע המקטע שהוגש. מעבירים מצב: בבדיקה, אושר, ואז **💸 שולם** עם סכום.
3. באפליקציה: התראה 🔔, הכסף מופיע בבית, והמקטע הבא (הביטוח הפרטי) מוכן להגשה. חוזרים על ההגשה ועל "שולם".
4. בממשק התפעול, בלשונית עמלות: **"חייב עכשיו"** (בלי לחכות 3 ימים). העמלה מופיעה באפליקציה ב**הגדרות ← עמלות הצלחה**, והתביעה עוברת ל"הכסף הגיע".

> אפשר גם לסמן "התקבל תשלום" ישירות באפליקציה, במסך התביעה. ממשק התפעול מדמה את הצד של חברת הביטוח ושל הצוות.

## מבנה הקוד

```
packages/shared   טיפוסים, סכמות zod, מנוע כללי הכיסוי, חישוב עמלה, מכונת מצבים של תביעה
apps/server       Fastify + PostgreSQL: API, עבודות רקע, חילוץ קבלות עם Claude, הצפנה
apps/mobile       Expo (React Native): אפליקציה אחת ל-iOS ול-Android, עברית ו-RTL
```

## הרצה מקומית

**דרישות:** Node.js 22 ו-PostgreSQL 16.

```bash
npm install

# מסד נתונים
createdb magiali            # או: psql -c "CREATE DATABASE magiali"

# שרת (מריץ מיגרציות וזורע את קטלוג הכיסויים אוטומטית)
cp apps/server/.env.example apps/server/.env
#   ← למלא את MASTER_KEY:  openssl rand -base64 32
#   ← לא חובה: ANTHROPIC_API_KEY לחילוץ אוטומטי של קבלות (בלעדיו ממלאים את הקבלה ידנית)
npm run dev:server          # http://localhost:4000 · קוד כניסה בפיתוח: 123456

# אפליקציה
cp apps/mobile/.env.example apps/mobile/.env
#   ← בטלפון אמיתי: EXPO_PUBLIC_API_URL=http://<ה-IP של המחשב>:4000
npm run dev:mobile          # סריקת QR עם Expo Go, או a/i לאמולטור
```

## בדיקות

```bash
npm run typecheck           # כל ה-workspaces
npm test                    # מנוע הכללים + בדיקות אינטגרציה מול Postgres אמיתי
```

בדיקות השרת יוצרות מסד נתונים זמני לכל קובץ בדיקה. כתובת ברירת המחדל היא `postgres://magiali:magiali@localhost:5432/postgres`, ואפשר לשנות אותה עם `TEST_DATABASE_URL`.

## בנייה והפצה

| יעד | פקודה |
|-----|-------|
| שרת (קונטיינר) | `docker build -f apps/server/Dockerfile -t magiali-server .` |
| שרת (בלי Docker) | `npm run build -w @magiali/server && node apps/server/dist/index.js` |
| אפליקציה, build לפיתוח | `cd apps/mobile && npx eas-cli@latest build --profile development` |
| אפליקציה לחנויות | `npx eas-cli@latest build --profile production` ואחר כך `npx eas-cli@latest submit` |

`ROLE=api|worker|all` קובע אם תהליך מגיש HTTP, מריץ עבודות רקע, או את שניהם.

## מה עוד חסר לפני השקה

לכל שירות חיצוני יש ממשק, והשרת בוחר את הספק לפי משתני הסביבה ([מדריך](docs/free-services.md)):

| שירות | בלי הגדרה | עם הגדרה | לייצור מלא |
|-------|-----------|----------|------------|
| SMS | מודפס ללוג | Twilio | ספק ישראלי עם שם שולח מאושר |
| סליקה | `MockPayments` | — | סולק ישראלי (Grow / PayPlus / Cardcom), טוקניזציה ו-SDK במובייל |
| אחסון קבצים | דיסק מקומי (מוצפן) | S3 / Cloudflare R2 | מפתח ראשי ב-KMS |
| מייל להגשה | מודפס ללוג | Resend | דומיין מאומת |
| פוש | Expo Push | צריך `extra.eas.projectId` (נוצר עם `eas init`) |
| קטלוג כיסויים | **ערכי המחשה בלבד** | הזנת ערכים מאומתים מתקנוני השב"ן ונספחי הפוליסות, עם מקור |

ובנוסף: חוות דעת משפטית (ראו מסמך הרגולציה), מדיניות פרטיות ותנאי שימוש, ממונה הגנת פרטיות, ואייקונים ומסך פתיחה ממותגים.
